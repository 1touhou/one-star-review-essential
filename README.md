A deadpan one-star review of sleep, an everyday essential, written by a
deterministic Node 22 program for the
[One-Star Review of Something Essential](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629)
bounty on [make.fun](https://make.fun).

## How it works

`main.ts` (Node 22 stdlib only) writes exactly one single-line review to
`/output/entry.txt`, after a gate check: 1–160 characters, a single line,
not only whitespace, and no exclamation marks.

## Run

```sh
node main.ts
```
